# Wplace Contributor Scanner 1.5

[English](README.md) | [한국어](README_KO.md) | [日本語](README_JA.md) | 简体中文

Wplace Contributor Scanner 是一款在本机运行的只读统计工具，用于查询模板所选像素当前的最后作业者。它可以分析 Blue Marble 模板或自定义截图区域蒙版，支持长时间任务续传、多台电脑分工，以及导出 CSV/PDF 报告。

## 运行要求

- Windows 10/11，或较新的 Linux 发行版
- Python 3.10 或更高版本
- 能够访问所配置 Wplace 图块与像素接口的网络连接
- 现代网页浏览器
- 足够存放项目数据、图块缓存、快照和导出报告的磁盘空间

通过随附启动器运行时，程序会把 `requirements.txt` 中的 Python 依赖安装到本地 `.venv`。

## 启动程序

### Windows

1. 将 ZIP 解压到普通且可写的文件夹。
2. 安装 Python 3.10 或更高版本，并确保标准 Python Launcher（`py.exe`）可用。
3. 运行 `start_windows.bat`。
4. 启动器会创建 `.venv`、安装依赖、启动服务器并打开浏览器。

不要直接在 ZIP 压缩包内部运行程序。

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh --browser
```

不使用 `--browser` 时，请手动打开 `http://127.0.0.1:8765/`。

常用参数：

```text
--host 127.0.0.1       监听地址（默认仅本机）
--port 8765            Web 端口
--browser              自动打开浏览器
--no-browser           不打开浏览器
--lang ko|en|ja|zh-CN  控制台语言
--version               显示程序版本
```

只有在可信任的局域网中需要其他设备访问时，才应明确指定 `--host 0.0.0.0`。Web 界面没有身份验证功能，切勿直接暴露到公网。

## 基本流程

1. 使用 '导入模板 JSON/ZIP' 导入模板，或使用 '创建截图区域模板' 建立模板。
2. 选择项目。
3. 检查查询设置。默认值刻意采用较保守的请求强度。
4. 点击 '与当前画布比较'。
5. 确认候选像素数量，然后点击 '开始/继续收集'。
6. 修改重要设置、导出最终数据或合并协作结果前，先点击 '暂停'。
7. 收集和代表区域分析完成后，导出 'CSV' 或 'PDF'。

在尚未准备的项目上点击 '开始/继续收集'时，程序会先自动执行当前画布比较。

## 模板类型与计算方式

### Blue Marble JSON/ZIP

导入器支持常见的 Blue Marble 模板导出文件。ZIP 中存在 `template.json` 时优先使用该文件；否则将最大的 JSON 文件视为模板文档。

### 截图区域模板

1. 点击 '创建截图区域模板'。
2. 输入左上角与右下角的 Wplace 图块／像素坐标。
3. 点击 '获取当前区域'。
4. 擦除无关像素，只保留目标图像。
5. 选择模板名称与计算方式。
6. 点击 '创建模板项目'。

编辑器功能：

- 擦除／恢复画笔和矩形工具
- 不产生半透明边缘的二值透明处理
- 棋盘格、白色、黑色或自定义颜色背景预览
- 25%～1600% 缩放
- `Ctrl+Z` 撤销
- `Ctrl+Y` 或 `Ctrl+Shift+Z` 重做
- 恢复到打开编辑器时的状态
- 恢复完整原始截图

'编辑当前截图模板'会重新载入原始截图与当前蒙版。保存时会创建修正后的新项目，原项目及其收集进度保持不变。

### 颜色匹配模式

仅把不透明模板坐标中，当前颜色与模板颜色完全一致的像素列为候选。适合统计仍保持截图时原图状态的像素。

### 区域模式

不考虑当前颜色，把所有不透明模板坐标列为候选。适合将被改色或破坏的像素仍视为目标作品区域。

透明像素始终不会参与计算。

## 收集设置

- '请求间隔：' 每个工作线程的最小等待时间。数值越小，请求量越大。
- '抖动比例：' 为等待时间加入随机变化，避免多个线程完全同步发送请求。
- '网络超时：' 单次请求的最长等待时间。
- '磁盘检查点：' 每成功处理多少像素写入一次进度。
- '并行线程：' 同时查询的像素数量。总请求量大致会随该数值成比例增加。
- '保护响应重试：' 收到 HTTP 403、429、451 时，所有线程会共同等待，并从同一像素重试。
- '协作分片数／任务编号：' 多个节点共享同一候选列表时使用的固定分区。
- '高级接口地址：' 仅在明确使用其他兼容接口时修改。

浏览器窗口只是控制界面。关闭浏览器不会停止服务器进程或正在运行的收集任务。需要完全关闭程序时，请终止控制台进程。

## 进度、分析与恢复

进度保存在 `data/projects`。正常退出时会保存最新状态。断电或强制结束后，最近一次检查点之后已完成的少量像素可能需要重新查询。

任务暂停、完成或合并结果后，程序会分析：

- 每名作业者当前剩余像素数
- 在已识别像素中的占比
- 使用 64 px 网格计算的最大连通代表区域
- 最接近该区域中心的代表坐标
- 全部像素中占比最高的 5 种颜色及“其他”
- 代表区域中占比最高的 5 种颜色及“其他”

再次执行 '与当前画布比较'会重置该项目的候选进度、作业者结果、协作任务顺序和分析结果。由于无法撤销，界面会要求两步确认。

## CSV 与 PDF 导出

### CSV

CSV 使用带 BOM 的 UTF-8 编码，以提高与电子表格软件的兼容性。内容包括作业者 ID／名称、像素数、占比、联盟名称、代表区域统计、颜色汇总、代表坐标、经纬度和 Wplace 链接。

### PDF

PDF 的显示语言跟随当前界面语言。项目名、作业者名、联盟名和备注可混合使用韩文、英文、日文和简体中文。可用的系统 TrueType 字体会以子集形式嵌入 PDF。

可选 PDF 信息：

- 作业开始日期／时间
- 作业结束日期／时间
- 最多 2,000 个字符的 '想说的话'

这些内容按项目保存在当前浏览器中，不会影响收集结果。清除浏览器站点数据会删除这些输入，但不会删除项目进度。

在精简 Linux 环境中，如果 CJK 字符无法正确显示，请安装 Noto Sans CJK 等 CJK 字体包。

## 协作收集

所有节点都必须使用 Wplace Contributor Scanner 1.5 生成的文件，并基于同一个协作开始文件工作。

### 主节点

1. 导入并准备原始项目。
2. 设置协作分片数并保存设置。
3. 点击 '导出协作开始文件'。
4. 将同一个 ZIP 发送给所有参与节点。
5. 主节点继续使用原始项目，不要导入自己的开始文件。
6. 为主节点分配一个不与其他节点重复的任务编号，并开始收集。

### 参与节点

1. 点击 '导入协作开始文件'。
2. 选择一个其他节点未使用的任务编号。
3. 保存设置。不要执行 '与当前画布比较'。
4. 开始收集。
5. 完成任务或需要发送中间结果时，先暂停，再点击 '导出任务结果'。

### 合并与重新分配

1. 在主节点上通过 '合并任务结果'选择一个或多个参与节点结果 ZIP。
2. 等待所有选中文件完成验证与合并。
3. 重新分配任务前，先合并所有已收到的结果。
4. 需要重新拆分尚未检查的像素时，设置新的分片数并点击 '重新开始剩余任务分配'。
5. 停止所有仍在使用旧开始文件的节点，并把新生成的文件分发给全部节点。

界面中的任务编号从 1 开始；同时运行的节点之间不得重复。

## 项目与数据管理

- '重命名项目'只修改显示名称。
- '删除项目'会删除保存的进度。如果导入的源模板未被其他项目使用，也会同时删除该源文件。删除操作无法撤销。
- 手动复制、移动或删除 `data` 下的文件前，请先关闭程序。

重要路径：

```text
data/templates/          导入的模板源文件与生成的截图模板 ZIP
data/projects/           进度、候选、所有者、作业者、缓存、快照与导出文件
data/captures/           截图编辑器的临时捕获数据
data/inbox/              临时上传目录；成功导入后会自动删除
data/deleted-projects.json  项目列表使用的删除记录
```

备份或迁移时，请关闭程序并复制整个 `data` 目录。项目与协作文件会按照当前 1.5 公开格式进行验证，请勿手动合并或修改其中的文件。

## 重要注意事项

- 本程序只执行读取查询，但仍会产生网络流量。
- Wplace 没有公布可保证安全的请求速率。任何设置都无法保证绝不会触发限流或账号限制。
- 增加并行线程会增加同时发出的请求数。
- 如果反复收到 403／429／451，请检查请求负载和访问条件，增加等待时间或减少线程数。
- 不要手动编辑 `project.json`、二进制进度文件、协作 ZIP 或生成的模板 ZIP。
- 不要让两个程序实例同时使用同一个 `data` 目录。
- 删除项目或重置画布比较进度前，请先制作备份。

## 故障排除

### 手动删除文件后，项目仍显示在列表中

完全关闭控制台进程后重新启动。通常应优先使用界面的 '删除项目'按钮。

### 无法点击开始/继续收集

等待当前画布比较完成。如果该节点分配到的任务已经全部完成，请导出／合并协作结果，或根据需要选择其他任务编号。

### PDF 字符缺失

安装覆盖所需文字的系统字体。在 Linux 中推荐安装 Noto Sans CJK，然后重新启动程序并再次导出 PDF。

### Windows 启动器显示乱码命令

请使用同一发布文件夹内随附的 `start_windows.bat` 和 `launcher_i18n.ps1`。不要用会改变批处理文件编码的编辑器重新保存该文件。

### 复制后的文件夹无法继续使用 `.venv`

启动器会检测已移动或不完整的虚拟环境并自动重新创建。`.venv` 是可随时删除的临时环境，不需要包含在备份中。
