작업·협업 안내

기준 노드1. 협업 시작`현재 그림과 비교`를 마친 원본 프로젝트에서 분할 수를 저장한 뒤 협업 시작 파일 내보내기를 한 번 실행합니다. 기준 노드는 파일을 다시 가져오지 않고 자기 작업 번호로 계속 수집합니다.
참여 노드2. 시작 파일 가져오기모든 참여 노드는 같은 시작 파일을 가져오고, 분할 수는 동일하게 두되 작업 번호만 서로 다르게 설정·저장한 뒤 수집합니다. `현재 그림과 비교`는 누르지 않습니다.
참여 노드3. 결과 전달완료하거나 중간 결과를 보낼 때 일시정지한 뒤 작업 결과 내보내기를 사용합니다. 이 파일을 기준 노드에 전달합니다. 기준 노드는 자기 결과가 이미 있으므로 보통 결과 파일을 내보내지 않습니다.
기준 노드4. 결과 병합·재분배작업 결과 병합으로 참여 노드 파일을 모두 합칩니다. 느린 작업을 다시 나누려면 모든 결과를 병합한 뒤 새 분할 수를 입력하고 남은 작업 분배 재시작을 만들어 모든 노드에 새로 배포합니다.

처리 방식

1. Blue Marble의 3×3 중앙점에서 목표 색상을 복원합니다.
2. 현재 1000×1000 타일을 내려받아 색상이 정확히 같은 픽셀만 후보로 저장합니다.
3. 병렬 워커가 서로 다른 후보를 나눠 조회하며 동일 픽셀을 중복 요청하지 않습니다.
4. 협업 시 후보 번호를 분할 수로 나눈 나머지 기준으로 작업을 고정 분배합니다.
5. 참여자는 같은 협업 시작 파일을 가져와 서로 다른 작업 번호를 선택한 뒤 작업 결과 파일을 내보냅니다.
6. 작업자 결과는 기본 100픽셀마다 디스크 체크포인트로 저장되며 설정에서 변경할 수 있습니다.
7. 429·403·451 응답은 모든 워커가 함께 대기한 뒤 같은 픽셀부터 자동 재시도합니다.
8. 정상 종료 시 마지막 결과까지 저장하며, 정전 시에는 마지막 체크포인트 이후 일부만 재조회될 수 있습니다.
