# Wplace Contributor Scanner 1.5.1

[English](README.md) | 한국어 | [日本語](README_JA.md) | [简体中文](README_ZH_CN.md)

Wplace Contributor Scanner는 템플릿이 지정한 픽셀의 **현재 마지막 작업자**를 조회하는 로컬 읽기 전용 통계 도구입니다. Blue Marble 템플릿이나 직접 만든 스크린샷 영역 템플릿을 사용할 수 있으며, 장시간 수집 재개, 여러 PC 협업, CSV/PDF 보고서 내보내기를 지원합니다.

## 필요 환경

- Windows 10/11 또는 최신 Linux 배포판
- Python 3.10 이상
- 설정된 Wplace 타일·픽셀 엔드포인트에 접속 가능한 인터넷 환경
- 최신 웹 브라우저
- 프로젝트 데이터, 타일 캐시, 그림과 보고서를 저장할 디스크 여유 공간

제공된 실행 스크립트는 현재 폴더의 `.venv`에 `requirements.txt`의 Python 패키지를 자동 설치합니다.

## 실행 방법

### Windows

1. ZIP을 쓰기 가능한 일반 폴더에 완전히 압축 해제합니다.
2. Python 3.10 이상을 설치하고 `py.exe` 런처가 동작하는지 확인합니다.
3. `start_windows.bat`을 실행합니다.
4. 가상환경 생성, 패키지 설치, 서버 시작 후 브라우저가 자동으로 열립니다.

ZIP 내부에서 직접 실행하지 마세요.

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh --browser
```

`--browser`를 생략했다면 브라우저에서 `http://127.0.0.1:8765/`를 엽니다.

주요 실행 옵션:

```text
--host 127.0.0.1       대기 주소. 기본값은 현재 PC에서만 접속 가능
--port 8765            웹 포트
--browser              브라우저 자동 실행
--no-browser           브라우저 자동 실행 안 함
--lang ko|en|ja|zh-CN  콘솔 표시 언어
--version               프로그램 버전 표시
```

신뢰할 수 있는 내부망의 다른 장비에서 접속해야 할 때만 `--host 0.0.0.0`을 명시하세요. 웹 화면에는 인증 기능이 없으므로 인터넷에 직접 노출하면 안 됩니다.

## 기본 사용 순서

1. **템플릿 JSON/ZIP 가져오기**로 템플릿을 가져오거나 **스크린샷 영역 템플릿 만들기**를 실행합니다.
2. 프로젝트를 선택합니다.
3. 조회 설정을 확인합니다. 기본값은 과도한 요청을 피하도록 보수적으로 설정되어 있습니다.
4. **현재 그림과 비교**를 누릅니다.
5. 후보 픽셀 수를 확인하고 **수집 시작/계속**을 누릅니다.
6. 주요 설정 변경, 최종 내보내기, 협업 결과 병합 전에는 **일시정지**합니다.
7. 수집과 대표 영역 분석이 끝나면 CSV 또는 PDF를 내보냅니다.

준비되지 않은 프로젝트에서 **수집 시작/계속**을 누르면 현재 그림 비교를 먼저 수행한 뒤 자동으로 수집을 시작합니다.

## 템플릿과 계산 방식

### Blue Marble JSON/ZIP

일반적인 Blue Marble 템플릿 내보내기 파일을 지원합니다. ZIP 루트에 `template.json`이 있으면 해당 파일을 사용하며, 없으면 ZIP 안에서 가장 큰 JSON 파일을 템플릿 문서로 사용합니다.

### 스크린샷 영역 템플릿

1. **스크린샷 영역 템플릿 만들기**를 누릅니다.
2. 그림 좌상단과 우하단의 Wplace 타일·픽셀 좌표를 입력합니다.
3. **현재 구간 가져오기**를 누릅니다.
4. 관계없는 영역을 지워 필요한 그림만 남깁니다.
5. 템플릿 이름과 계산 방식을 선택합니다.
6. **템플릿 프로젝트 생성**을 누릅니다.

편집 기능:

- 지우기·복원 브러시와 사각형 도구
- 반투명 가장자리 없이 완전히 지우는 이진 투명 마스크
- 격자무늬·흰색·검은색·직접 선택 배경
- 25%~1600% 확대
- `Ctrl+Z` 되돌리기
- `Ctrl+Y` 또는 `Ctrl+Shift+Z` 다시 실행
- 편집기를 열었을 때의 상태로 복원
- 캡처 원본 전체 복원

**현재 스크린샷 템플릿 수정**은 원본 캡처와 현재 마스크를 다시 불러옵니다. 저장하면 수정된 새 프로젝트를 만들며 기존 프로젝트와 수집 진행은 보존됩니다.

### 색상 일치 기준

현재 색상이 템플릿 색상과 정확히 같은 불투명 좌표만 후보로 지정합니다. 캡처 당시 그림이 현재까지 유지된 픽셀을 집계할 때 적합합니다.

### 영역 기준

현재 색상과 관계없이 모든 불투명 템플릿 좌표를 후보로 지정합니다. 색이 바뀌거나 훼손된 픽셀도 해당 그림 영역에 포함해야 할 때 적합합니다.

투명 픽셀은 두 방식 모두 제외됩니다.

## 조회 설정

- **요청 간격:** 워커별 최소 요청 간격입니다. 줄일수록 전체 요청량이 증가합니다.
- **무작위 지터:** 여러 워커 요청이 같은 시점에 몰리지 않게 지연을 흔듭니다.
- **네트워크 타임아웃:** 한 요청을 기다리는 최대 시간입니다.
- **디스크 체크포인트:** 성공 픽셀 몇 개마다 진행 상태를 저장할지 정합니다.
- **병렬 워커:** 동시에 조회하는 수입니다. 워커 수에 비례해 동시 요청량도 증가합니다.
- **보호 응답 자동 재시도:** HTTP 403·429·451을 받으면 모든 워커가 함께 기다린 뒤 같은 픽셀부터 재시도합니다.
- **협업 분할 수/내 작업 번호:** 같은 후보 목록을 여러 노드가 고정 분배할 때 사용합니다.
- **고급 엔드포인트:** 호환되는 별도 엔드포인트를 의도적으로 사용할 때만 변경합니다.

브라우저는 조작 화면일 뿐입니다. 브라우저를 닫아도 콘솔 서버가 살아 있으면 수집은 계속됩니다. 프로그램을 종료하려면 콘솔 프로세스를 종료하세요.

## 진행 저장·분석·복구

진행 데이터는 `data/projects`에 저장됩니다. 정상 종료 시 마지막 상태를 저장하며, 정전이나 강제 종료 시에는 마지막 체크포인트 이후의 일부 픽셀만 다시 조회될 수 있습니다.

수집 일시정지·완료 또는 협업 결과 병합 후 다음 항목을 분석합니다.

- 작업자별 현재 잔존 픽셀 수
- 확인된 작업자 픽셀 중 지분
- 64px 격자로 연결한 가장 큰 대표 영역
- 대표 영역 중심에 가장 가까운 실제 소유 픽셀의 대표 좌표
- 전체 상위 5개 색상과 기타
- 대표 영역 상위 5개 색상과 기타

**현재 그림과 비교**를 다시 실행하면 해당 프로젝트의 후보 목록, 작업자 결과, 진행률, 협업 작업 순서, 분석 결과가 초기화됩니다. 되돌릴 수 없어 2단계 확인을 요구합니다.

## CSV와 PDF

### CSV

스프레드시트 호환을 위해 UTF-8 BOM으로 저장됩니다. 작업자 ID·이름, 픽셀 수와 지분, 연합명, 대표 영역, 색상 통계, 대표 좌표, 위도·경도, Wplace 링크를 포함합니다.

### PDF

PDF 표시 언어는 현재 UI 언어를 따릅니다. 프로젝트명, 작업자명, 연합명, 하고 싶은 말에는 한국어·영어·일본어·중국어를 혼합해 사용할 수 있으며 사용 가능한 시스템 TrueType 글꼴을 PDF에 부분 포함합니다.

PDF 추가 입력:

- 작업 시작 날짜·시간
- 작업 종료 날짜·시간
- 최대 2,000자의 **하고 싶은 말**

입력값은 현재 브라우저에 프로젝트별로 저장되며 수집 통계에는 사용되지 않습니다. 브라우저 사이트 데이터를 지우면 이 입력값만 사라지고 프로젝트 진행은 삭제되지 않습니다.

최소 설치 Linux에서 CJK 글자가 나오지 않으면 Noto Sans CJK 같은 한·중·일 글꼴 패키지를 설치하고 다시 내보내세요.

## 협업 사용법

모든 노드는 Wplace Contributor Scanner 1.5.1에서 만든 파일을 사용하고, 같은 협업 시작 파일을 기준으로 작업해야 합니다.

### 기준 노드

1. 원본 프로젝트를 가져와 현재 그림 비교를 완료합니다.
2. 협업 분할 수를 정하고 설정을 저장합니다.
3. **협업 시작 파일 내보내기**를 실행합니다.
4. 같은 ZIP을 모든 참여 노드에 전달합니다.
5. 기준 노드는 원본 프로젝트를 그대로 사용하며 자기 시작 파일을 다시 가져오지 않습니다.
6. 다른 노드와 겹치지 않는 작업 번호를 선택하고 수집합니다.

### 참여 노드

1. **협업 시작 파일 가져오기**를 실행합니다.
2. 다른 노드와 겹치지 않는 내 작업 번호를 정합니다.
3. 설정을 저장합니다. **현재 그림과 비교**는 누르지 않습니다.
4. 수집을 시작합니다.
5. 완료하거나 중간 결과를 보낼 때 일시정지 후 **작업 결과 내보내기**를 실행합니다.

### 병합과 재분배

1. 기준 노드에서 **작업 결과 병합**으로 참여 노드 결과 ZIP을 하나 이상 선택합니다.
2. 각 파일의 검증과 병합이 끝날 때까지 기다립니다.
3. 남은 작업을 다시 나누기 전 받은 결과를 모두 병합합니다.
4. 새 분할 수를 입력하고 **남은 작업 분배 재시작**을 실행합니다.
5. 이전 시작 파일로 작업하던 모든 노드를 중지하고 새 파일을 전체 노드에 다시 배포합니다.

UI의 작업 번호는 1부터 시작하며 동시에 작업하는 각 노드에서 중복되면 안 됩니다.

## 프로젝트와 데이터 관리

- **프로젝트 이름 변경:** 화면에 표시되는 이름만 바꿉니다.
- **프로젝트 삭제:** 진행 데이터를 삭제하며, 다른 프로젝트가 사용하지 않는 원본 템플릿도 함께 삭제합니다. 되돌릴 수 없습니다.
- `data` 파일을 직접 복사·이동·삭제하기 전에는 프로그램을 완전히 종료하세요.

주요 경로:

```text
data/templates/            가져온 원본 템플릿과 생성된 스크린샷 템플릿 ZIP
data/projects/             진행, 후보, 소유자, 작업자, 캐시, 그림, 내보낸 파일
data/captures/             스크린샷 편집기의 임시 캡처
data/inbox/                임시 업로드. 성공한 가져오기는 자동 삭제
data/deleted-projects.json 프로젝트 목록에서 삭제 상태를 유지하는 기록
```

백업이나 다른 PC 이동 시 프로그램을 종료하고 `data` 폴더 전체를 복사하세요. 프로젝트·협업 파일은 현재 1.5.1 공개 형식으로 검증되므로, 내부 파일을 수동으로 합치거나 수정하지 마세요.

## 주의사항

- 쓰기 작업을 하지 않는 읽기 전용 조회 도구지만 네트워크 요청은 발생합니다.
- Wplace는 보장된 안전 요청량을 공개하지 않았습니다. 어떤 설정도 제한이나 계정 제재 가능성이 전혀 없다고 보장할 수 없습니다.
- 병렬 워커를 늘리면 동시 요청량도 증가합니다.
- 403·429·451이 반복되면 워커 수를 줄이고 요청 간격을 늘리세요.
- `project.json`, 이진 진행 파일, 협업 ZIP, 생성된 템플릿 ZIP을 직접 편집하지 마세요.
- 같은 `data` 폴더를 두 프로그램 인스턴스에서 동시에 사용하지 마세요.
- 프로젝트 삭제 또는 비교 초기화 전에 필요한 파일을 백업하세요.

## 문제 해결

### 폴더를 지웠는데 프로젝트 목록에 남아 있음

콘솔 프로세스를 완전히 종료하고 다시 실행하세요. 직접 삭제보다 **프로젝트 삭제** 버튼을 권장합니다.

### 수집 시작/계속 버튼이 비활성화됨

현재 그림 비교가 끝날 때까지 기다리세요. 현재 노드에 배정된 작업을 이미 완료했다면 협업 결과를 내보내거나 병합하고 필요한 경우 작업 번호를 조정하세요.

### PDF 글자가 빠짐

해당 언어를 포함하는 시스템 글꼴을 설치하세요. Linux에서는 Noto Sans CJK를 권장합니다. 설치 후 프로그램을 재시작하고 PDF를 다시 만드세요.

### Windows 실행창에서 깨진 명령이 출력됨

같은 배포 폴더의 `start_windows.bat`과 `launcher_i18n.ps1`을 함께 사용하세요. 배치 파일의 인코딩을 바꾸는 편집기로 다시 저장하지 마세요.

### 폴더 이동 후 `.venv`를 사용할 수 없음

실행 스크립트가 이동되었거나 불완전한 가상환경을 감지하면 자동으로 다시 만듭니다. `.venv`는 언제든 다시 생성할 수 있으므로 백업할 필요가 없습니다.
