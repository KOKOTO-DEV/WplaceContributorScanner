# Wplace Contributor Scanner 1.5.1

[English](README.md) | [한국어](README_KO.md) | 日本語 | [简体中文](README_ZH_CN.md)

Wplace Contributor Scanner は、テンプレートで選択したピクセルについて、現在の最終作業者を調べるローカル動作・読み取り専用の統計ツールです。Blue Marble テンプレートまたはスクリーンショット領域から作成したマスクを解析し、長時間の収集の再開、複数 PC への作業分割、CSV/PDF レポートの出力に対応します。

## 動作要件

- Windows 10/11、または比較的新しい Linux ディストリビューション
- Python 3.10 以降
- 設定された Wplace タイル／ピクセルエンドポイントへ接続できるインターネット環境
- 最新の Web ブラウザー
- プロジェクトデータ、タイルキャッシュ、スナップショット、出力レポートを保存できる空き容量

付属ランチャーから起動すると、`requirements.txt` の Python パッケージがローカルの `.venv` にインストールされます。

## 起動方法

### Windows

1. ZIP を通常の書き込み可能なフォルダーへ展開します。
2. Python 3.10 以降をインストールし、標準の Python Launcher（`py.exe`）が利用できる状態にします。
3. `start_windows.bat` を実行します。
4. ランチャーが `.venv` を作成し、依存関係をインストールしてサーバーとブラウザーを起動します。

ZIP 内から直接実行しないでください。

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh --browser
```

`--browser` を付けない場合は、ブラウザーで `http://127.0.0.1:8765/` を開いてください。

主なオプション：

```text
--host 127.0.0.1       待ち受けアドレス（既定：この PC のみ）
--port 8765            Web ポート
--browser              ブラウザーを自動的に開く
--no-browser           ブラウザーを開かない
--lang ko|en|ja|zh-CN  コンソール表示言語
--version               プログラムのバージョンを表示
```

信頼できる LAN 内の別端末から接続する場合に限り、明示的に `--host 0.0.0.0` を指定してください。Web 画面には認証機能がないため、インターネットへ直接公開しないでください。

## 基本的な使い方

1. **テンプレート JSON/ZIP を取り込む**でテンプレートを読み込むか、**スクリーンショット領域テンプレートを作成**します。
2. 使用するプロジェクトを選択します。
3. 問い合わせ設定を確認します。初期値は負荷を抑えた設定です。
4. **現在の画像と比較**をクリックします。
5. 候補ピクセル数を確認し、**収集開始／続行**をクリックします。
6. 重要な設定変更、最終出力、共同作業結果の結合を行う前に **一時停止**します。
7. 収集と代表領域解析が完了したら、**CSV** または **PDF** を出力します。

未準備のプロジェクトで **収集開始／続行**を押すと、先に現在のキャンバスとの比較が自動実行されます。

## テンプレートの種類と計算方式

### Blue Marble JSON/ZIP

一般的な Blue Marble テンプレートのエクスポート形式を取り込めます。ZIP 内に `template.json` がある場合はそのファイルを使用し、ない場合は最も大きい JSON ファイルをテンプレート文書として扱います。

### スクリーンショット領域テンプレート

1. **スクリーンショット領域テンプレートを作成**をクリックします。
2. 左上と右下の Wplace タイル／ピクセル座標を入力します。
3. **現在の領域を取得**をクリックします。
4. 関係のないピクセルを消し、対象の絵だけを残します。
5. テンプレート名と計算方式を選択します。
6. **テンプレートプロジェクトを作成**をクリックします。

編集機能：

- 消去／復元ブラシ、消去／復元矩形ツール
- 半透明の縁を作らない二値透明処理
- 市松模様、白、黒、任意色の背景プレビュー
- 25%～1600% の拡大表示
- `Ctrl+Z` で元に戻す
- `Ctrl+Y` または `Ctrl+Shift+Z` でやり直す
- 編集画面を開いた時点の状態へ戻す
- 取得した元画像全体へ戻す

**現在のスクリーンショットテンプレートを編集**では、元の取得画像と現在のマスクを再度開けます。保存すると修正版の新しいプロジェクトが作成され、既存プロジェクトと収集進捗は変更されません。

### 色一致方式

不透明なテンプレート座標のうち、現在の色がテンプレート色と完全に一致するピクセルだけを候補にします。取得時の絵が現在も維持されているピクセルを調べる用途に適しています。

### 領域方式

現在色に関係なく、不透明なテンプレート座標をすべて候補にします。色が変更された、または破壊されたピクセルも対象領域に含めたい場合に適しています。

透明ピクセルは常に除外されます。

## 収集設定

- **リクエスト間隔：** ワーカーごとの最小待機時間です。短くすると通信量が増えます。
- **ジッター率：** 待機時間にランダムな変動を加え、ワーカーの送信時刻が完全に同期しないようにします。
- **ネットワークタイムアウト：** 1 回のリクエストを待つ最大時間です。
- **ディスクチェックポイント：** 何ピクセル成功するごとに進捗を保存するかを指定します。
- **並列ワーカー：** 同時に照会するピクセル数です。総リクエスト量はおおむねこの値に比例して増えます。
- **保護応答の再試行：** HTTP 403、429、451 を受信すると、すべてのワーカーが同時に待機し、同じピクセルから再試行します。
- **共同作業の分割数／作業番号：** 複数ノードで同じ候補一覧を固定分割するときに使用します。
- **高度なエンドポイント：** 互換エンドポイントを意図的に使用する場合以外は変更しないでください。

ブラウザーは操作画面にすぎません。ブラウザーを閉じても、サーバープロセスや実行中の収集は停止しません。完全に終了するときはコンソールプロセスを停止してください。

## 進捗、解析、復旧

進捗は `data/projects` に保存されます。通常終了時には最新状態が保存されます。停電や強制終了が起きた場合、最後のチェックポイント以降に完了した分だけ再照会が必要になることがあります。

収集の一時停止、完了、結果結合後には次の解析を実行します。

- 作業者ごとの現在残存ピクセル数
- 識別済みピクセル内の割合
- 64 px グリッドを使用した最大連結代表領域
- 代表領域の中心に最も近い代表座標
- 全体色の上位 5 色と「その他」
- 代表領域色の上位 5 色と「その他」

同じプロジェクトで **現在の画像と比較**を再実行すると、候補進捗、作業者結果、共同作業の順序、解析結果がリセットされます。元に戻せないため、画面では 2 段階の確認が必要です。

## CSV／PDF 出力

### CSV

表計算ソフトとの互換性のため、CSV は UTF-8 BOM 付きで保存されます。作業者 ID／名前、ピクセル数、割合、連合名、代表領域統計、色集計、代表座標、緯度／経度、Wplace リンクを含みます。

### PDF

PDF の表示言語は現在の画面言語に従います。プロジェクト名、作業者名、連合名、メモでは韓国語、英語、日本語、簡体字中国語を混在させられます。利用可能なシステム TrueType フォントはサブセットとして PDF に埋め込まれます。

任意入力項目：

- 作業開始日時
- 作業終了日時
- 最大 2,000 文字の **言いたいこと**

これらは現在のブラウザーにプロジェクト単位で保存され、収集結果には影響しません。ブラウザーのサイトデータを削除すると入力内容は消えますが、プロジェクト進捗は削除されません。

最小構成の Linux 環境で CJK 文字が正しく表示されない場合は、Noto Sans CJK などの CJK フォントをインストールしてください。

## 共同作業

すべてのノードで Wplace Contributor Scanner 1.5.1 が生成したファイルを使用し、同じ共同作業開始ファイルを基準にしてください。

### 基準ノード

1. 元プロジェクトを取り込み、現在キャンバスとの比較を完了します。
2. 共同作業の分割数を設定して保存します。
3. **共同作業開始ファイルを出力**をクリックします。
4. 同じ ZIP をすべての参加ノードへ渡します。
5. 基準ノードでは元プロジェクトをそのまま使用し、自分の開始ファイルを取り込まないでください。
6. 基準ノードにも他と重複しない作業番号を設定して収集を開始します。

### 参加ノード

1. **共同作業開始ファイルを取り込む**をクリックします。
2. 他のノードと重複しない作業番号を選択します。
3. 設定を保存します。**現在の画像と比較**は実行しないでください。
4. 収集を開始します。
5. 完了時または途中結果を送るときは一時停止し、**作業結果を出力**をクリックします。

### 結合と再分配

1. 基準ノードで **作業結果を結合**から 1 個以上の参加ノード結果 ZIP を選択します。
2. 選択した全ファイルの検証と結合が終わるまで待ちます。
3. 残作業を再分配する前に、受け取った結果をすべて結合します。
4. 未確認ピクセルだけを再分割する場合、新しい分割数を設定して **残り作業の分配を再開始**をクリックします。
5. 古い開始ファイルを使用中の全ノードを停止し、新しく生成されたファイルを全ノードへ配布します。

画面上の作業番号は 1 から始まり、同時に動作するノード間で重複してはいけません。

## プロジェクトとデータ管理

- **プロジェクト名を変更**は表示名だけを変更します。
- **プロジェクトを削除**は保存済み進捗を削除します。取り込んだ元テンプレートを他のプロジェクトが使用していない場合、その元ファイルも削除されます。削除は元に戻せません。
- `data` 配下のファイルを手動でコピー、移動、削除する前にプログラムを終了してください。

主なパス：

```text
data/templates/          取り込んだテンプレートと生成したスクリーンショットテンプレート ZIP
data/projects/           進捗、候補、所有者、作業者、キャッシュ、スナップショット、出力物
data/captures/           スクリーンショット編集用の一時取得データ
data/inbox/              一時アップロード。成功した取り込みは自動削除
data/deleted-projects.json  プロジェクト一覧で使用する削除記録
```

バックアップまたは移行時はプログラムを終了し、`data` ディレクトリ全体をコピーしてください。プロジェクト／共同作業ファイルは現在の 1.5.1 公開形式として検証されるため、内部ファイルを手動で結合または変更しないでください。

## 重要な注意事項

- 本ツールは読み取り専用の照会を行いますが、ネットワーク通信は発生します。
- Wplace は安全が保証されたリクエスト量を公開していません。どの設定でもレート制限やアカウント制限が起きないことは保証できません。
- 並列ワーカーを増やすほど同時リクエスト数が増えます。
- 403／429／451 が繰り返される場合は、通信負荷や接続条件を確認し、間隔を増やすかワーカー数を減らしてください。
- `project.json`、バイナリ進捗ファイル、共同作業 ZIP、生成済みテンプレート ZIP を手動編集しないでください。
- 同じ `data` ディレクトリを 2 つのプログラムインスタンスから同時に使用しないでください。
- プロジェクト削除や比較進捗のリセット前にバックアップを作成してください。

## トラブルシューティング

### ファイルを手動削除してもプロジェクトが一覧に残る

コンソールプロセスを完全に終了してから再起動してください。通常は画面の **プロジェクトを削除**を使用してください。

### 収集開始／続行が押せない

現在キャンバスとの比較が完了するまで待ってください。そのノードに割り当てられた作業がすでに完了している場合は、共同作業結果を出力／結合するか、必要に応じて別の作業番号を選択してください。

### PDF の文字が欠ける

必要な文字体系を含むシステムフォントをインストールしてください。Linux では Noto Sans CJK を推奨します。インストール後にプログラムを再起動し、PDF を再出力してください。

### Windows ランチャーに文字化けしたコマンドが表示される

同じリリースフォルダーにある `start_windows.bat` と `launcher_i18n.ps1` をそのまま使用してください。バッチファイルの文字コードを変更するエディターで保存し直さないでください。

### コピーしたフォルダーで `.venv` を再利用できない

ランチャーは移動済み、または不完全な仮想環境を検出すると自動的に作り直します。`.venv` は削除可能な一時環境であり、バックアップに含める必要はありません。
